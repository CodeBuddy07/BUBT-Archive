# BUBT Assignments and Tasks

This repository contains problem-solving code and assignments for various courses at BUBT.

## Structure

The repository is organized by course. Inside each course directory, you'll find folders for assignments, class tests, etc.

Example:
- `CSE_101_Structured_Programming/`
  - `Assignments/`
  - `CT_1/`

You can add more courses as new folders in the root directory.
